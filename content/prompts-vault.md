# Vault de prompts de imágenes

Banco de prompts para generar imágenes de posts. Reglas:

- Formato: cuadrado **1080x1080** (o 2048x2048 y el script lo baja). JPEG/PNG.
- Marca: azul **#2563eb** + blanco. Estilo minimalista, moderno, cálido.
- CTA visible: botón "Crea tu tienda gratis". Link real de los posts: **https://t.co/phJghRDEoU**
- Al usar un prompt, añade el tag **`-USED`** al lado del título y anota el archivo (`→ 0N.jpg`).
- Los `-USED` ya salieron; para el próximo lote toma los que NO tienen `-USED`.

Leyenda: `-USED` = ya publicado · (sin tag) = disponible.
